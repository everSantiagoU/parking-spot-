# Parking Spot

Monorepo inicial para el sistema académico Parking Spot. El repositorio contiene la estructura base para un monolito modular con backend Java/Spring Boot y frontend React/TypeScript.

## Estructura

- `backend/`: aplicación Spring Boot organizada por capas hexagonales.
- `frontend/`: aplicación mínima React con Vite.
- `infrastructure/`: espacio reservado para artefactos de infraestructura.
- `docs/`: espacio para documentación académica y técnica.
- `scripts/`: automatizaciones locales futuras.

Consulta los README de `backend/` y `frontend/` para requisitos de ejecución.
